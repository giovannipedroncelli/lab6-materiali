lab6/incontro-4/kit/02-teoria/03-regole.md

Tre regole per le consegne AI-powered

  1. Il prodotto funzionante è necessario, ma pesa meno delle evidenze.
  2. Le evidenze richieste sono dichiarate prima.
  3. C'è sempre un momento in presenza in cui lo studente spiega o modifica.

I test di GitHub Actions dicono se il codice si comporta bene, non se lo studente l'ha capito: riscontro, non voto. Una consegna AI-proof molto efficace: «scrivi tre test per questa specifica prima di vedere qualunque codice».
