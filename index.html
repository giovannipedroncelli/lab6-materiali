Il caso di due studenti sul vostro computer

Marco e Giulia sono due repository Git veri, ciascuno chiuso in un file: marco.bundle e giulia.bundle.

Senza installare niente: apri il notebook in Colab ed esegui le celle in ordine. Scarica i due studenti, mostra la storia dei commit, esegue i test e la prova del docente.

Sul proprio PC (servono Git e Python con pytest): scaricate i due file in una cartella, poi dal terminale (su Windows: Git Bash; python invece di python3):

git clone marco.bundle marco
git clone giulia.bundle giulia
cd marco
git log --oneline
python3 -m pytest -q
python3 -c "from report import report; print(report([]))"
cd ../giulia
git log --oneline
python3 -m pytest -q
python3 -c "from report import report_giornata; print(report_giornata([]))"

Risultati attesi: Marco 1 commit, 5 passed, poi ValueError con la lista vuota. Giulia 9 commit, 1 failed, 7 passed, poi (0, 0, None, 0). Per la prima versione dell'IA di Giulia: git switch --detach HEAD~5, python3 -m pytest -q (3 test falliti), poi git switch main.
